# 日志系统实施计划

## 1. 创建日志配置文件

**文件**: `backend/app/core/logging_config.py`

* 配置日志格式：`时间戳 - 模块名 - 级别 - 消息`

* 配置日志级别：INFO（生产环境可调整为WARNING）

* 配置日志轮转：10MB文件大小，保留5个备份

* 创建两个日志文件：

  * `backend/logs/app.log` - 应用主日志

  * `backend/logs/api.log` - API接口日志

## 2. 修改应用主入口

**文件**: `backend/app/main.py`

* 导入日志配置

* 添加应用启动日志

* 添加请求日志中间件（记录所有API请求）

## 3. 添加认证接口日志

**文件**: `backend/app/api/routes/auth.py`

* 登录接口：记录请求参数、认证结果、用户信息

* 登出接口：记录登出操作

* 获取当前用户接口：记录访问信息

## 4. 添加任务接口日志

**文件**: `backend/app/api/routes/tasks.py`

* 创建任务接口：记录文件上传、任务创建信息

* 运行任务接口：记录任务执行开始、处理过程、完成状态

* 获取任务列表接口：记录查询参数

* 获取任务详情接口：记录任务ID和查询结果

* 下载文件接口：记录文件下载操作

## 5. 重启后端服务

* 停止当前运行的后端服务

* 重新启动后端服务

* 验证日志文件是否正常生成

## 6. 测试所有后端接口

* 测试认证接口（登录、登出、获取用户信息）

* 测试任务接口（创建、运行、查询、下载）

* 验证日志记录是否完整

## 7. 测试所有前端页面

* 测试登录页面

* 测试任务管理页面

* 测试文件上传功能

* 测试任务执行和结果下载

## 日志格式示例

```
2026-02-05 10:30:45,123 - app.main - INFO - 应用启动成功
2026-02-05 10:30:50,456 - app.api.routes.auth - INFO - 用户登录成功: username=admin
2026-02-05 10:31:00,789 - app.api.routes.tasks - INFO - 创建任务: task_id=t_abc123, file_type=customs
```
