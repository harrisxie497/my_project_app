# 清关文件加工流程规划（最终版）

## 一、整体流程架构

```
源Excel文件 → 读取数据 → 处理表头行 → 按列处理 → 应用规则（含AI） → 生成结果Excel
```

### 核心组件
1. **ExcelReader**：读取源Excel文件
2. **HeaderProcessor**：处理表头行（B1、E1、H1）
3. **FieldProcessor**：按列处理字段
4. **RuleEngine**：执行规则（包括AI规则）
5. **ExchangeRateService**：汇率服务（外网API）
6. **DeepSeekAIService**：AI服务（DeepSeek API）
7. **ExcelWriter**：生成结果Excel文件

## 四、R列汇率计算（重点）

### 4.1 计算逻辑

**R列（インボイス価格）计算公式**：
```
日元价格 = 原始文件中R列的值（外币价格） × Q列通货代码对应的汇率
```

**示例**：
- 原始文件中R列 = 100（美元价格）
- Q列通货代码 = USD
- USD/JPY汇率 = 150
- 计算：100 × 150 = 15000
- 取整：15000
- 验证：符合正则 `^\d+$`
- 结果：15000

### 4.2 R列处理函数

```python
def calc_invoice_price_fx_round(self, input_data: Dict[str, Any], params: Dict[str, Any]) -> int:
    """
    计算インボイス価格（汇率换算）
    
    输入：
        - input_data: {
            "original_price": 原始文件中R列的值（外币价格）,
            "currency_code": Q列的通货代码（如：USD、EUR等）
        }
        - params: 规则参数
    
    输出：
        - 日元价格（取整）（int）
    
    处理流程：
        1. 从原始文件读取R列的值（外币价格）
        2. 从Q列获取通货代码（如：USD、EUR等）
        3. 调用汇率API获取该通货代码对JPY的汇率
        4. 计算：日元价格 = 外币价格 × 汇率
        5. 取整（四舍五入）
        6. 验证结果符合正则表达式 ^\d+$（纯数字）
        7. 返回结果
    """
    original_price = float(input_data.get('original_price', 0))
    currency_code = input_data.get('currency_code', 'USD')
    
    # 获取汇率（从currency_code到JPY）
    exchange_rate = self.exchange_rate_service.get_rate(currency_code, 'JPY')
    
    # 计算
    jpy_price = original_price * exchange_rate
    
    # 取整
    jpy_price = int(round(jpy_price))
    
    # 验证正则
    import re
    if not re.match(r'^\d+$', str(jpy_price)):
        raise ValueError(f"计算结果不符合正则验证：{jpy_price}")
    
    return jpy_price
```

### 4.3 依赖关系

**R列的依赖**：
- **Q列**（通货代码）：必须先处理完成
- **原始文件中R列**（外币价格）：从源文件读取

**处理顺序**：
1. 先处理Q列（获取通货代码）
2. 再处理R列（使用Q列的通货代码）

```python
import requests
import json

class DeepSeekAIService:
    """DeepSeek AI服务"""
    
    def __init__(self, api_key: str, base_url: str = "https://api.deepseek.com/v1"):
        self.api_key = api_key
        self.base_url = base_url
        self.model = "deepseek-chat"
    
    def chat(self, prompt: str, system_prompt: str = None) -> str:
        """
        调用DeepSeek聊天API
        
        输入：
            - prompt: 用户提示词
            - system_prompt: 系统提示词（可选）
        
        输出：
            - AI响应文本
        """
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json"
        }
        
        messages = []
        if system_prompt:
            messages.append({"role": "system", "content": system_prompt})
        messages.append({"role": "user", "content": prompt})
        
        payload = {
            "model": self.model,
            "messages": messages,
            "temperature": 0.3,
            "max_tokens": 200
        }
        
        response = requests.post(
            f"{self.base_url}/chat/completions",
            headers=headers,
            json=payload,
            timeout=30
        )
        
        response.raise_for_status()
        result = response.json()
        return result["choices"][0]["message"]["content"]
```

### 6.2 汇率服务类

```python
import requests
import json
from datetime import datetime, timedelta
from typing import Dict, Optional

class ExchangeRateService:
    """汇率服务"""
    
    def __init__(self, api_key: str, base_url: str = "https://v6.exchangerate-api.com/v6"):
        self.api_key = api_key
        self.base_url = base_url
        self.cache = {}
        self.cache_duration = timedelta(hours=1)
    
    def get_rate(self, from_currency: str, to_currency: str = "JPY") -> float:
        """
        获取汇率
        
        输入：
            - from_currency: 源货币代码（如：USD）
            - to_currency: 目标货币代码（默认：JPY）
        
        输出：
            - 汇率（float）
        """
        cache_key = f"{from_currency}_{to_currency}"
        
        # 检查缓存
        if cache_key in self.cache:
            cached_time, cached_rate = self.cache[cache_key]
            if datetime.now() - cached_time < self.cache_duration:
                return cached_rate
        
        # 调用API
        url = f"{self.base_url}/latest"
        params = {
            "apikey": self.api_key,
            "base": from_currency,
            "symbols": to_currency
        }
        
        response = requests.get(url, params=params, timeout=10)
        response.raise_for_status()
        
        data = response.json()
        rate = data["rates"][to_currency]
        
        # 缓存结果
        self.cache[cache_key] = (datetime.now(), rate)
        
        return rate
```
