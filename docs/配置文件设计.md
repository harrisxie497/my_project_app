## 1. 项目概述

本系统用于构建一个 **配置驱动的 Excel 自动化处理引擎**，适用于：

* 日本清关文件（Customs）
* 日本佐川派送文件（Delivery）

**核心目标：**

> 用户上传源 Excel
> → 系统按配置规则自动生成结果 Excel
> → 全流程可配置、可审计、可复现

---

## 2. 系统总体设计

### 输入 / 输出模型

* **输入文件（source）**：用户上传 Excel
* **输出文件（output）**：系统生成 Excel
* 系统内部允许多步处理
* **配置层 & 数据层只认 source / output 两类文件**

### 设计关键点

* ❌ 无中间文件实体
* ✅ 所有逻辑通过配置驱动
* ✅ 每一列的生成逻辑可追溯

---

## 3. 核心设计原则

1. **配置即执行计划**
2. **一列一行配置**
3. **规则与字段解耦**
4. **默认值显式化**
5. **支持 AI / 程序 / 外部接口混合执行**
6. **结果可复现、过程可审计**

---

## 4. 配置体系总览（三表模型）

| 表名               | 职责                 |
| ---------------- | ------------------ |
| file_definitions | 定义 Excel 文件结构      |
| field_pipelines  | 定义结果 Excel 每一列如何生成 |
| rule_definitions | 定义规则本身如何执行         |

一句话记忆：

> **file_definitions：Excel 长什么样**
> **field_pipelines：这一列怎么来**
> **rule_definitions：规则怎么跑**

## 9. 执行流程说明

### 9.1 执行顺序

1. 读取 file_definitions
2. 加载 source Excel
3. 按 order 排序 field_pipelines
4. 对每一列执行：

   * map_op
   * rule_ref（顺序执行）
5. 写入 output Excel
6. 记录审计日志

## 一、Customs · file_definitions（文件结构定义）

### 1️⃣ Customs · source（清关源文件）

| 字段             | 值       | 说明               |
| -------------- | ------- | ---------------- |
| file_type      | CUSTOMS | 清关文件类型           |
| file_role      | source  | 用户上传的原始清关 Excel  |
| sheet_name     | 单件尺寸重量  | Excel 中的 Sheet 名 |
| header_row     | 2       | 第 2 行是表头         |
| data_start_row | 3       | 第 3 行开始是数据       |
| columns_json   | A–AY    | 定义了源文件所有可读取列     |

**这一行的含义：**

> 告诉系统：
>
> * 去 Excel 的 `单件尺寸重量` 这个 Sheet
> * 第 2 行找表头
> * 从第 3 行开始逐行读取数据
> * A–AY 列都可能被后续规则引用

---

### 2️⃣ Customs · output（清关结果文件）

| 字段             | 值       | 说明         |
| -------------- | ------- | ---------- |
| file_type      | CUSTOMS | 清关文件类型     |
| file_role      | output  | 系统生成的结果文件  |
| sheet_name     | 单件尺寸重量  | 输出 Sheet 名 |
| header_row     | 2       | 输出表头所在行    |
| data_start_row | 3       | 输出数据起始行    |
| columns_json   | A–AN    | 定义最终清关结果列  |

**这一行的含义：**

> 告诉系统：
>
> * 结果 Excel 也叫 `单件尺寸重量`
> * 只输出 A–AN 列
> * 后续 field_pipelines **只能生成这些列**
