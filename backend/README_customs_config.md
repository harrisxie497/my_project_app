# 清关配置初始化说明

## 问题修复

原 `init_customs_config.sql` 文件存在以下问题：
1. 使用了 PostgreSQL 特有的 `INSERT ... ON CONFLICT` 语法，MySQL 不支持
2. `id` 字段没有提供 UUID 值

## 解决方案

创建了 `init_customs_config_fixed.py` Python 脚本替代原 SQL 文件：
- 使用 `INSERT IGNORE` 避免重复插入
- 自动生成 UUID
- 使用参数化查询防止 SQL 注入

## 执行结果

执行后的数据统计：
- **清关字段映射记录数**: 50
- **启用字段数**: 34
