1. **F列（货物重量）处理错误**

   - 输出包含序号和空格
   - 需要修复AI返回结果的解析逻辑

4. **K列（輸入者住所）输出格式错误**

   - 可能是依赖列Y的数据问题导致的

   - 添加 `policy_copy_optional_text` 规则，或
   - 修改Y列配置为使用 `policy_ai_text_dress_clean` 规则

3. **优化AI输出结果的解析逻辑**
   - 移除输出结果中的序号和其他不必要的格式
